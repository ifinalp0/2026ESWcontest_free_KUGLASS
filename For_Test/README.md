# For_Test

이 폴더는 KUGLASS의 독립 시험용 펌웨어와 실험 프로젝트를 제품 코드에서 분리해 보관하는 영역입니다. ESP32_A와 ESP32_B에 사용하는 제품 펌웨어는 각각 루트의 `ESP32_A_Algo/`, `ESP32_B_Algo/`이며, 이 폴더의 프로젝트는 제품 빌드에 포함되지 않습니다.

## 사용 원칙

- 일반적인 제품 개발, 코드 탐색, 아키텍처 판단에서는 이 폴더를 참조하지 않습니다.
- 특정 하드웨어 시험이나 시험 코드 작업이 명시된 경우에만 필요한 하위 프로젝트를 사용합니다.
- 시험 코드의 프로토콜, 핀 설정과 안전 조건은 제품 펌웨어와 다를 수 있습니다. 각 프로젝트의 README를 먼저 확인합니다.
- 시험 결과를 제품 코드에 반영할 때는 `ESP32_A_Algo/`, `ESP32_B_Algo/`, `hardware/`의 canonical 계약을 기준으로 다시 검증합니다.
- 제품 프로젝트의 `host_tests/`는 제품 소스와 함께 유지되는 계약 테스트이므로 이 폴더의 독립 시험 프로젝트와 구분합니다.

## 프로젝트

| 경로 | 목적 | 제품 펌웨어와의 관계 |
| --- | --- | --- |
| `ESP32_A_TESTT/` | A→B UART 명령 송신 시험 | `type=set`, `mi[]` 형식을 사용하므로 현재 B 제품 계약과 비호환 |
| `ESP_Camera/` | OV2640 캡처·JPEG·전송 단독 시험 | 제품용 카메라 서비스는 `ESP32_A_Algo/`가 독립적으로 소유 |
| `ESP32_B_TEST/` | 내부 MI를 사용하는 B 출력·안전 입력 시험 | 제품 통신 경로를 대체하지 않는 독립 시험 프로파일 |
| `ESP32_B_TEST_Enable_high/` | enable 조건을 강제한 제한적 계측 시험 | Power Stage 분리 등 README의 안전 조건이 필수 |
| `ESP32_TEST/` | ESP32_B DevKit과 Logic Carrier 사이 GPIO 배선 계측 | SPWM·UART·Power Stage 구동을 제외한 저전압 핀 시험 |

각 프로젝트는 해당 하위 폴더를 ESP-IDF 프로젝트 루트로 사용해 별도로 빌드합니다.
